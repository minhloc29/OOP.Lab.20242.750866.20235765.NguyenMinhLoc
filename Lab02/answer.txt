Question 3: Is JAVA a Pass by Value or a Pass by Reference programming language?
Java is a pass-by-value language. When you pass a data type like int, float... to a method, a copy of the value is passed.
Change to this copy within the method do not affect the original variable.

Question 4: After the call of swap(jungleDVD, cinderellaDVD) why does the title of these two objects still remain?
Because Java is a pass-by-value language, the 2 arguments in swap is just copies of real variables, so change in these copies does not affect the real variables.

Question 5: After the call of changeTitle(jungleDVD, cinderellaDVD.getTitle()) why is the title of the JungleDVD changed?
When calling this method, will have a copy of dvd. But dvd is the reference that holds memory address to a variable, so whether copy or not will point to a variable. So
dvd.setTitle will really change the variable's title. But when calling dvd = new DigitalVideoDisc(...), this dvd is just a copy, so change of it do not effect anything.
